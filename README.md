# SOS

iOS向けのSOS共有・フラッシュ通知・疑似着信を試すSwiftUIアプリです。メッセージを共有シートで送信でき、位置情報の添付を選べます。ブラウザなどのダミー画面も含まれます。

## 起動

1. iOS 17.5以降のSDKに対応するXcodeで `SOS.xcodeproj` を開きます。
2. Signing & Capabilitiesで自分のTeamを選びます。必要に応じてBundle Identifierを変更してください。
3. SOSターゲットと実行端末を選び、Runを実行します。

外部APIキーは不要です。フラッシュや位置情報、共有先への送信は実機で確認してください。`SOSTests` と `SOSUITests` はXcodeのTestから実行できます。

## データと注意事項

位置情報を添付すると、緯度・経度が共有メッセージに含まれます。共有内容と送信先を確認してください。選択した写真、実際のSOSメッセージや位置情報、端末のログはリポジトリへ追加しないでください。個人データの作業用保存先は `private-data/` または `exports/` にしてください。

試作アプリです。緊急通報サービスへの接続や救援を保証する機能は実装されていません。
